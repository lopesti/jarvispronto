## 📋 Sobre o Projeto

JarvisPronto é um assistente virtual completo que integra **WhatsApp, Inteligência Artificial e Banco de Dados** para automatizar atendimentos, vendas e suporte ao cliente.

### 🚀 Funcionalidades

- 📱 **WhatsApp integrado** - Conexão via Baileys com QR Code
- 🤖 **IA Inteligente** - Gemini e Groq com fallback automático
- 🗄️ **Banco de Dados** - PostgreSQL para persistência de dados
- 📊 **Dashboard** - Interface administrativa em Next.js
- 🧪 **Simulação** - 4 agentes com diferentes níveis de consciência
- 🔐 **Autenticação JWT** - Segurança nas rotas da API
- 🐳 **Containerizado** - Docker Compose para fácil deploy
